# NorthStar GitHub Pages host files

This repository publishes host-level crawler files for [NorthStar Client Showcase](https://northstarrecovery.github.io/client-showcase/). Search crawlers read `/robots.txt` at the host root. The sitemap index points to the showcase sitemap; the host landing page directs visitors to the showcase.

The website itself remains in [NorthStarRecovery/client-showcase](https://github.com/NorthStarRecovery/client-showcase). This repository contains only public hosting configuration and no source-library data.
